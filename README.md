# CA Knowledge Hub

Bilal's master offline study + professional knowledge system for the CA journey —
present CAF studies, future articleship, and post-qualification professional life.

**Offline-first, deterministic (no AI guessing). Study material only —
never client data.**

## Run on Windows

1. Get the `ca-knowledge-hub-windows-v1.0.1.zip` package.
2. Extract it, then double-click **`hub/run_windows.bat`**.
3. The first run installs Python + dependencies automatically and opens the app
   at http://localhost:8506.

Full user guide: [`hub/README.md`](hub/README.md) · `USER_GUIDE.md`

## Run on any device (in your browser)

Host it free on **Streamlit Community Cloud**:

1. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
2. **New app** → repository `Bilal13za/ca-knowledge-hub`, branch `main`,
   main file path **`hub/app.py`**.
3. **Deploy** — after a minute or two you get a link like
   `https://ca-knowledge-hub.streamlit.app` that opens on any phone, tablet,
   or computer.

Caveat: anything you save in the cloud copy is temporary — it resets when the
app sleeps from inactivity. The Windows version above is the full,
keep-everything version.
