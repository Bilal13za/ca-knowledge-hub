# CA Knowledge Hub — User Guide

**Status:** Phase 1A — this guide is written as the UI lands (Phase 1C).
Early truthful summary:

## What exists now (Phase 1A)

The Hub's foundation: a versioned local database, a module system, a
manual cloud-folder workflow, and an export format. There is not yet a
user interface — that arrives in Phase 1C.

## The workflow (once Phase 1C lands)

1. Download documents from TeraBox into a folder you choose.
2. In the Hub: Storage → point at that folder → **Refresh Library**.
3. Search everything (documents + knowledge records) from global search.
4. Pick a **workspace** (e.g. "Audit + Tax") to scope a task.
5. Curate knowledge records; verify them against primary sources;
   the Hub tracks review due dates.
6. **Backup** regularly; restores are verified automatically.

## Modes

- **Study Mode** — syllabus-mapped notes, flashcards, practice, revision.
- **Practice Mode** — workflows: reconciliations, procedures, checklists.
- **Professional Mode** — research, templates, registers (post-qualification).

Workspaces never make professional conclusions for you — they present
each domain's material and leave judgement to you.
